Liver Disease Prediction using Machine Learning

Project Overview

This project focuses on predicting liver disease using Machine Learning techniques and comparing multiple models to identify the most effective approach. The objective of this project is to analyze healthcare-related data and apply machine learning algorithms for disease prediction and performance evaluation.

⸻

Dataset Information

The project uses liver patient health parameters including:

* Age
* Gender
* Total Bilirubin
* Direct Bilirubin
* Alkaline Phosphotase
* Alamine Aminotransferase
* Aspartate Aminotransferase
* Total Proteins
* Albumin
* Albumin and Globulin Ratio

⸻

Machine Learning Models Used

* Logistic Regression
* Decision Tree
* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Random Forest

⸻

Best Model Performance (Random Forest)

* Accuracy: 73.5%
* Precision: 79.2%
* Recall: 87.4%
* F1 Score: 83.1%

⸻

Techniques Applied

* Data preprocessing
* Missing value handling
* Label encoding
* Feature scaling
* Exploratory Data Analysis (EDA)
* Correlation heatmap
* Feature importance analysis
* Confusion matrix evaluation
* ROC curve analysis

⸻

Technologies Used

Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn

⸻

Results

Best Performing Model: Random Forest

The Random Forest model achieved the strongest performance among all implemented models and demonstrated strong capability in identifying positive liver disease cases while maintaining balanced predictive performance.
