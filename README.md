# Liver Disease Prediction using Machine Learning

## Project Overview
This project focuses on predicting liver disease using Machine Learning techniques and comparing multiple models to identify the most effective approach.

## Dataset Information
The project uses liver patient health parameters including:

- Age
- Gender
- Total Bilirubin
- Direct Bilirubin
- Alkaline Phosphotase
- Alamine Aminotransferase
- Aspartate Aminotransferase
- Total Proteins
- Albumin
- Albumin and Globulin Ratio

## Machine Learning Models Used
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Random Forest

## Best Model Performance (Random Forest)

Accuracy: 73.5%
Precision: 79.2%
Recall: 87.4%
F1 Score: 83.1%

## Techniques Applied
Data preprocessing  
Missing value handling  
Label encoding  
Feature scaling  
Exploratory Data Analysis  
Correlation heatmap  
Feature importance analysis  
Confusion matrix  
ROC curve evaluation

To apply machine learning techniques in healthcare data analysis and gain practical experience in data preprocessing, model evaluation, and predictive modeling.
